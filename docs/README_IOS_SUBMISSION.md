## ❓ Common Questions - Quick Answers

### **Q: What's the difference between TestFlight and Production?**
**A:** TestFlight is for private testing (fast updates), Production is live on App Store (slow updates, needs review). They are SEPARATE - updating TestFlight does NOT update production!

**Full answer:** [TESTFLIGHT_VS_PRODUCTION_GUIDE.md](./TESTFLIGHT_VS_PRODUCTION_GUIDE.md)

---

### **Q: How long does App Review take?**
**A:** First submission: 2-5 days. Updates: 1-3 days. Can be faster or slower.

**Full answer:** [APP_STORE_SUBMISSION_GUIDE.md](./APP_STORE_SUBMISSION_GUIDE.md) → Step 9

---

### **Q: How do I update my live app?**
**A:** Create new build, increment version number, upload, submit for review (takes 1-3 days).

**Full answer:** [TESTFLIGHT_VS_PRODUCTION_GUIDE.md](./TESTFLIGHT_VS_PRODUCTION_GUIDE.md) → Section "How Updates Work"

### **Q: What happens if my app gets rejected?**
**A:** Read rejection reason, fix issues, increment build number, resubmit. Usually reviewed faster.

**Full answer:** [APP_STORE_SUBMISSION_GUIDE.md](./APP_STORE_SUBMISSION_GUIDE.md) → Step 10.6

**Answer:** Complete step-by-step process in:
- [APP_STORE_SUBMISSION_GUIDE.md](./APP_STORE_SUBMISSION_GUIDE.md)

**Quick summary:**

7. If approved, app goes live

---

### **3. "I have already put the app in TestFlight. When I update TestFlight, does production update too?"**

**Answer:** **NO! They are separate!**

**Full explanation:** [TESTFLIGHT_VS_PRODUCTION_GUIDE.md](./TESTFLIGHT_VS_PRODUCTION_GUIDE.md) → Section "Your Specific Questions Answered"

**Key points:**
- TestFlight updates are instant (after first approval)
- Production updates require full App Review (2-5 days)
- You must manually submit to production
- TestFlight and Production can have different versions

---

### **4. "How can I get the latest version on production?"**

**Answer:** Upload new build, select it in App Store Connect, submit for review, wait for approval.

**Full process:** [TESTFLIGHT_VS_PRODUCTION_GUIDE.md](./TESTFLIGHT_VS_PRODUCTION_GUIDE.md) → Section "Q2: How do I get the latest version on production?"

**Steps:**
1. Create update in code
2. Increment version number (1.0.0 → 1.0.1)
3. Archive and upload
4. Select build in App Store Connect
5. Submit for review
6. Wait 1-3 days (faster for updates)
7. App goes live after approval
